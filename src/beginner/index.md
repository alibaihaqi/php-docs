# Beginner PHP Tutorials

Build a small JSON HTTP API on PHP's built-in server, step by step. Each tutorial adds a new concept while extending the running artifact.

## Learning Path

| # | Tutorial | Concepts |
|---|----------|----------|
| 01 | [Install PHP](./01-install-php) | Toolchain setup, `php -v`, `php -S` |

More pages continue this ladder toward a working JSON endpoint — variables and types, control flow, functions, arrays, and finally a `php -S`-served JSON response. Tracked as follow-up work.

## Prerequisites

- [PHP installed](../introduction/getting-started)
- Basic programming knowledge (variables, loops, functions)

Start with [01 Install PHP](./01-install-php).
